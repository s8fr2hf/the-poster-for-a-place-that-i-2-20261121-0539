A travel poster for Luminara, a place that isn't there: a bay where the sea glows after dark, under a spiral lighthouse and an aurora sky. The poster is a 1024x1024 PNG; `main.py` copies it to `/output/entry.png`.

## Run it

```sh
python3 main.py
```

The poster art was composed in this session (`compose.py` documents the build: base art plus the hand-set LUMINARA title and tagline).
